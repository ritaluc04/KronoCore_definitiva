# 👋 ¡Bienvenido a KronoCore!

¡Hola! Te damos la bienvenida al repositorio principal de **KronoCore**, una plataforma integral de gestión empresarial (ERP/CRM) diseñada para centralizar y simplificar el día a día de cualquier negocio.

Este proyecto nace como Trabajo de Fin de Grado (TFG) y busca ofrecer una solución completa, moderna y escalable bajo una arquitectura **Multi-Tenant** (multi-empresa).

## 🚀 ¿Qué hay en este proyecto?

KronoCore está dividido en tres grandes bloques que trabajan juntos en armonía:

- 🐘 **Backend (Spring Boot & PostgreSQL):** El cerebro de la operación. Una API REST segura alojada en Azure, protegida con tokens JWT (RBAC) y diseñada con un patrón de desnormalización selectiva para asegurar el historial contable.
- 💻 **Panel Web (Vanilla JS):** Un Frontend de administración súper rápido y ligero, sin dependencias pesadas, construido bajo una arquitectura modular de *Screen Controllers*.
- 📱 **App Móvil (Flutter):** La herramienta de bolsillo para el equipo y los clientes. Interfaz fluida, gestión de estado con Provider y enrutamiento con GoRouter.

## 🛠️ Lo que puedes hacer con KronoCore

- **CRM y Agenda:** Gestionar clientes y reservas sin perder detalle.
- **Ventas y Finanzas:** TPV, generación de facturas y control de gastos.
- **Inventario:** Control de stock y alertas en tiempo real.
- **Kanban:** Organización visual de las tareas de todo tu equipo.
